VALLEY STATION CHURCH OF GOD - CONNECT / MINISTRIES UPDATE

This update adds three separate boxes under the 'A place to connect. A way to serve.' section:
- Sunday School: Sundays 9:30 AM, Adult Sanctuary Class and Bible classes for all ages.
- Men's Fellowship: a separate ministry card replacing the combined Women & Men box.
- Women's Ministries: its own ministry card.

It retains Kids Church (Sunday 11:00 AM and Wednesday 6:30 PM), the Ladies Prayer and Visitation Team (Tuesday 9:00 AM), the winter Sunday evening notice, the monthly event slideshow wiring and the 2027 theme banner wiring.

This ZIP includes only index.html. It does not replace the slideshow images or settings, or your announcements, sermons, Vimeo live links and Clover giving.

PUBLISH:
1. Back up your existing index.html in GitHub, especially if you changed it since adding Kids Church.
2. Open https://github.com/tjbass2655/valley-station-church-website
3. Select Add file > Upload files.
4. Upload the extracted index.html from this ZIP.
5. Commit changes on the main branch. Cloudflare Pages should deploy automatically.
6. Visit https://myvscog.org/#ministries and refresh.

If GitHub will not replace index.html using its upload screen, open index.html, click Edit, and replace its contents with the updated file contents, then commit. Do not delete the whole repository or any folders.
