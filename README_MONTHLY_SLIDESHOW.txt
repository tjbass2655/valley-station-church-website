VALLEY STATION CHURCH OF GOD - MONTHLY EVENT SLIDESHOW WITH 2027 THEME

THIS READY-TO-UPLOAD PACKAGE
- Adds the manually controlled Monthly Church Event Slideshow directly under the Events area of your homepage.
- Uses the seven original announcement flyers from your November 22 PDF, one flyer per slide.
- Ends with your existing blue-and-gold 2027 theme banner: THERE IS STILL MORE! (Ephesians 3:20).
- The 2027 banner is marked as a final slide, so new monthly flyers entered in Pages CMS still appear BEFORE it.
- Includes arrow buttons, mobile swipe, keyboard arrow navigation, and a link to view each poster full-size.
- Does not autoplay, giving viewers time to read each flyer.

INSTALL (ONCE, USING GITHUB)
1. Download and extract the ZIP. Do NOT upload the ZIP itself to GitHub.
2. Open https://github.com/tjbass2655/valley-station-church-website and sign in.
3. For safety, make a backup of the current index.html and .pages.yml files before replacing them, especially if you have made any further website design changes since the last upgrade.
4. Click Add file > Upload files. Drag ALL files/folders from the extracted folder, retaining their folder structure.
5. When prompted, commit the replacements to the main branch.
6. Cloudflare Pages will publish the change automatically.
7. Open https://myvscog.org/#news and scroll to Monthly Church Event Slideshow.

THIS PACKAGE UPDATES ONLY
  index.html
  .pages.yml
  events-slideshow.css
  events-slideshow.js
  content/event-slides.json
  assets/event-slides/ (8 poster files)
  README_MONTHLY_SLIDESHOW.txt

DO NOT DELETE OR REPLACE THESE EXISTING CHURCH CONTENT FILES
  content/announcements.json
  content/events.json
  content/sermons.json
  content/livestream.json
  content/service-links.json
Existing Vimeo event settings and Clover giving links are not replaced.

UPDATE SLIDES EACH MONTH USING PAGES CMS
1. Sign in at https://app.pagescms.org and open valley-station-church-website.
2. Choose Monthly Event Slideshow on the left.
3. Click Add an item, type the title and month, upload ONE event picture, and optionally add a caption.
4. For old event flyers, click the trash icon. Keep the 2027 theme entry.
5. Do NOT turn on "Keep this as the final slide" for ordinary announcements.
6. For the 2027 theme entry, leave the Keep-as-final switch ON.
7. Save. GitHub and Cloudflare will automatically publish changes.
8. The 2027 banner stays last even if you add more December flyers after it.

NOTES
- Each poster is a separate image, not a full page with seven tiny pictures.
- Some November 2026 holiday flyers will be dated after Thanksgiving. Remove those in Pages CMS when no longer relevant.
- If the slide editor does not appear, make sure the hidden configuration file is named .pages.yml (leading period).
- If you recently changed index.html or .pages.yml directly in GitHub, compare these replacements with your latest files before committing, so later customizations are not lost.
