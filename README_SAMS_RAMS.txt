VALLEY STATION CHURCH OF GOD - MINISTRY CARD UPDATE

This updates only the ministry cards on the homepage:
* Renames the existing Seniors & Fellowship box to SAMS: Senior Adult Ministry.
* Adds a new separate RAMS: Real Adult Ministry box for younger adults.

There are no changes to Vimeo, Clover links, slideshow JSON, service schedules, announcements or the Pages CMS configuration in this package.

HOW TO PUBLISH:
1. First, BACK UP your current GitHub index.html file, especially if you have made other homepage edits since the recent Connect & Ministries update.
2. In your GitHub repo, upload the index.html from this ZIP to the TOP LEVEL of the repository (not a subfolder).
3. Commit the change to main, and Cloudflare Pages should publish it automatically.
4. Refresh https://myvscog.org/#ministries and look for SAMS and RAMS.

CAUTION: GitHub upload of index.html REPLACES your existing homepage. This is based on the latest homepage copy prepared during our conversation. If you have edited index.html elsewhere since then, compare first to ensure newer changes are not overwritten. Content files managed by Pages CMS are not included in this ZIP.
